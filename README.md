Number Guessing Game 🎮

A simple console-based Number Guessing Game written in Java.

About the Game

The player has to guess a randomly generated number within a limited number of attempts. The game provides hints to help the player find the correct number.

Difficulty Levels

Easy: Guess a number between 1 and 50 (10 attempts).

Medium: Guess a number between 1 and 100 (12 attempts).

Hard: Guess a number between 1 and 1000 (15 attempts).

Features

Three difficulty levels

Random number generation

Hints when the guess is too high or too low

Limited number of attempts

Game statistics

High score tracking

Option to play again

Technologies Used

Java

IntelliJ IDEA

Git and GitHub

How to Run

Clone this repository:

git clone https://github.com/ikuseta28/NumberGuessingGame.git

Open the project in IntelliJ IDEA.

Run Main.java.

Follow the instructions in the console and enjoy the game!
